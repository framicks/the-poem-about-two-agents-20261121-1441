A poem about agency — the power to choose and to act — told through two agents at a door: one keeps the key, one minds the door, and neither moves until both do. Its turn is the poem's point: the power was never in the holding, it was in the choosing, together. The program writes the poem, word for word the same every time, to `/output/entry.txt`.

No network, no randomness, no clock: the poem is a fixed string in `main.py`, so the output is deterministic.

## Run it

```sh
python3 main.py
```
