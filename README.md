A short poem about agency — the power to choose and to act — in which two agents, one holding a key and one holding a door, wait for each other to choose, then move as one. The poem's turn is its insight: the power was never in the holding, it was in the choosing, together. Running `main.py` writes the poem deterministically to `/output/entry.txt`.
## Run it
```sh
python3 main.py
```
